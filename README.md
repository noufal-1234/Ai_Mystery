# AI Mystery Room

For the production deployment walkthrough, see [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). A Render Blueprint is included in `render.yaml`.

An AI-powered, single-player mystery investigation. Each case is generated by Google Gemini, stored in MongoDB, and served through an Express API. The culprit and solution remain private until the player submits an accusation.

## Requirements

- Node.js 20 or later and npm
- MongoDB (local Community Server or MongoDB Atlas)
- A Google Gemini API key

## Run locally

1. Copy `server/.env.example` to `server/.env` and set `MONGODB_URI`, `GEMINI_API_KEY`, and a long random `SESSION_SECRET`.
2. Copy `client/.env.example` to `client/.env` if the API is not at `http://localhost:5000/api/v1`.
3. Install dependencies from the project root with `npm install`, then run `npm install --prefix server` and `npm install --prefix client`.
4. Run `npm run dev` from the root. The React app is at http://localhost:5173 and the API is at http://localhost:5000.

Cases require working MongoDB and Gemini credentials. The app reports a clear configuration error when either service is unavailable; it does not substitute a hardcoded mystery. Gemini also generates evidence photographs when the selected image model is available; an unavailable image provider falls back to a clearly marked descriptive exhibit. CCTV uses explicitly simulated playback unless a video provider is added. Session cookies are HTTP-only and cases are scoped to the anonymous browser session that created them. Clearing site cookies loses access to that browser's cases.

## Build

Run `npm run build` from the root to build the client. Run `npm start` from the root to start the API (MongoDB must be available).

## MVP behavior

- 50–2,000 character scenario, optional title, Easy/Medium/Hard, 3–6 suspects.
- Server-side Gemini JSON generation with Zod validation and one retry.
- MongoDB persistence for generated cases, evidence, progress, and accusation.
- Evidence categories: message logs, descriptive image exhibits, simulated CCTV sequences, and documents.
- One final accusation per case. Correct answers score 100; incorrect answers score 0. Both reveal the saved solution.

The image provider is a separate Gemini image-generation adapter configured with `IMAGE_PROVIDER` and `IMAGE_MODEL`. CCTV is an explicitly labeled simulated sequence; video provider integration remains optional.
